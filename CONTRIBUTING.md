# Contributing

VertiMosaic welcomes reproducible research and engineering contributions. Please keep changes CPU-compatible, preserve vertical feature separation, avoid row-level private-data logging, and add tests for protocol changes.

Before opening a pull request run:

```bash
ruff check .
ruff format --check .
mypy src/vertimosaic
pytest -q --cov=vertimosaic
bandit -r src
python -m build
twine check dist/*
```

Do not commit raw external datasets, credentials, Kaggle files, or generated private artifacts. Measured result claims must be generated by code and accompanied by configuration and provenance.
