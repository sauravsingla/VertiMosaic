# VertiMosaic — Vertical Federated Learning Research Explorer

Interactive browser-based exploration of reproducible benchmark evidence generated by [VertiMosaic](https://github.com/sauravsingla/VertiMosaic).

The Space visualizes the same synthetic VFL experiment families published in the [VertiMosaic VFL Benchmark dataset](https://huggingface.co/datasets/sauravsingla08/VertiMosaic-VFL-Benchmark):

- VFL Logistic Regression vs VFL Histogram GBDT
- party ablation across Bank, Telecom, Insurance and Retail roles
- partial entity overlap
- inference/training party dropout
- controlled feature drift
- communication, timing and memory measurements

The Space is static and browser-only. GitHub Actions regenerates `data.json` from VertiMosaic's experiment code and publishes the resulting evidence payload through Hugging Face Trusted Publishers.

## Privacy boundary

VertiMosaic demonstrates raw-feature locality in a research VFL simulator. It does not claim cryptographic privacy, private set intersection, MPC, homomorphic encryption, secure aggregation, collusion resistance, malicious-party security or formal differential privacy.

## Data boundary

The Space uses VertiMosaic-generated synthetic benchmark evidence. It does not redistribute UCI, OpenML or IEEE-CIS source rows. The separate four-industry external benchmark is semi-synthetic: its public source datasets do not represent the same real individuals.
