# External datasets

VertiMosaic supports public-source adapters for:

- Bank: UCI Default of Credit Card Clients (`350`, DOI `10.24432/C55S3H`).
- Telecom: UCI Iranian Churn (`563`, DOI `10.24432/C5JW3Z`).
- Insurance: `freMTPL2freq` / `freMTPL2sev` via OpenML IDs `41214` / `41215`.
- Retail: UCI Online Retail (`352`, DOI `10.24432/C5BW33`).

Retrieval is an explicit user action. Provider metadata is written into `data/provenance/`. VertiMosaic code licensing does not relicense these datasets.

The four datasets do not identify the same individuals. Four-party cross-industry experiments are therefore externally grounded and semi-synthetic, not real cross-industry record linkage.
