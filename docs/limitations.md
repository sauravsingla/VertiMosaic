# Limitations

VertiMosaic is a CPU research implementation. The four-industry external benchmark uses real source-domain data but semi-synthetic cross-domain linkage because the public sources do not represent the same individuals. It is not evidence of deployment performance on real cross-industry customers.

Communication bytes are simulated payload estimates, not measured network traffic or latency. Default VFL protocols do not provide cryptographic security. External dataset availability, provider metadata, and licensing can change and should be verified at retrieval time.
