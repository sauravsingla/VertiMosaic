# Semi-synthetic cross-domain linkage

`CopulaLinker` creates target-blind donor assignments using unsupervised numeric summary factors, empirical ranks, an approximately Gaussian latent representation, configurable shared dependence, and nearest donor selection.

The Bank target is explicitly excluded from the observed-target linkage score. The resulting linkage is a research benchmark construction, not a private set intersection protocol and not evidence that source records belong to the same person.

Linkage manifests should record seed, method, cross-party correlation, anchor size, and donor-reuse statistics.
