# VertiMosaic experiment manifest

**Working paper title:** *VertiMosaic: CPU-Efficient Vertical Federated Learning Across Heterogeneous Industry Data*

**Technical subtitle:** *A Reproducible Tabular Benchmark with External Data Grounding, Partial Entity Overlap, Party Dropout and Vertical Histogram Boosting*

All paper values must be generated from measured result files. No metric is manually typed into a paper table or figure.

The IEEE-CIS mode is a two-party linked sanity benchmark using the exact `TransactionID` intersection and observed `isFraud`; it is not a four-industry benchmark. Source files remain authorized local inputs, are not redistributed, and are not required by ordinary CI. The run records local source-file SHA-256 checksums, train-only party-local preprocessing, pseudonymous exported entity IDs, and the standard reproducibility bundle.

The publication artifact builder reads `predictions.parquet`, `training_history.csv`, experiment CSVs and benchmark CSVs to generate the paper table and figures. The repository must not substitute manually entered measurements when a required artifact is absent; missing measured inputs are treated as errors.
